# PHEAT Planning Artifacts

Planning notes, user decisions, and questions/answers are kept in this directory so
project intent stays versioned with the implementation.

- `2026-05-13-plan.md`: implementation plan and scope decisions.
- `2026-05-19-mmcif-support.md`: mmCIF coordinate I/O plan and chain ID decisions.
- `2026-05-19-repository-hardening.md`: repository review and hardening plan.
- `questions-and-answers.json`: structured record of questions, answers, and user notes.

When new planning decisions are made, update both the human-readable notes and the
structured Q&A log when applicable.
