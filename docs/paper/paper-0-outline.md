## Proposed Title

PHEAT: an open toolkit for reproducible protein heavy-atom reference corpora,
geometry reconstruction, and molecular-modelling benchmarks

## Abstract Skeleton

Background: reproducible protein-structure reference datasets require explicit
source, filter, parser, and generated-artifact provenance.

Scientific Contribution: PHEAT introduces an open, schema-validated workflow for
generating reproducible protein heavy-atom reference corpora from public or
user-defined structural datasets. Unlike general structure parsers or fixed
benchmark datasets, PHEAT couples corpus selection, coordinate normalization,
residue-geometry reconstruction, decoy-generation scaffolds, scoring-table
construction hooks, and provenance capture into one reproducible toolkit.
